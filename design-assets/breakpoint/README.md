# Breakpoint local preview artwork

- `berlin-london-landmarks-v2.png` is the original transparent illustration generated with the built-in Image Gen tool on 14 October 2026. It depicts Brandenburg Gate and Big Ben as playful miniature landmarks, not a past conference photograph.
- `landmarks-prompt-v2.md` records the final prompt. References were screenshots captured from the existing Superteam Germany local page and the official `https://solana.com/breakpoint` hero. Those screenshots informed palette and mood; no official logo was recreated.
- The page serves the 1200 × 800 transparent WebP at `public/images/breakpoint/berlin-london-landmarks-v2.webp`. It is a format/size conversion of the original, preserving its alpha channel.
- Plane, ticket, message, connection, idea and community SVGs in that same public folder are rendered from the installed Lucide React icon library. The inline luggage and party-popper icons in the merch and side-event cards use the same library. Its license is preserved as `lucide-license.txt` and inside each public SVG/inline copy. Pause/play icons belong to the earlier local iteration and are no longer displayed.

Magic UI Text Animate inspired the native CSS/JavaScript reveals. The current refinement uses native card layouts and reflective highlights inspired by Bento Grid and Glare Hover; the earlier marquee and border beam were removed. The boarding pass uses a native CSS lilac/mint backlight inspired by [Magic UI Backlight](https://magicui.design/docs/components/backlight), inspected on 15 October 2026. Its latest adjustment increases the glow's opacity and soft spread so the colour is easier to see, retaining the same palette, eight-second motion and reduced-motion behavior. No Magic UI package was added, and no official conference programme was copied into the page.

The roomier five-card bento follows the varying card spans in the supplied [Magic UI Bento Grid reference](https://magicui.design/docs/components/bento-grid), inspected on 15 October 2026. Connections spans two desktop columns beside building, with community, merch and side events below. It uses the existing Lucide stickers with a larger featured sticker; no new art or motion was introduced.

The country background shapes use `de.svg` and `gb.svg` from [flag-icons](https://github.com/lipis/flag-icons), downloaded on 14 October 2026. Originals and `flag-icons-license.txt` are preserved here, and the MIT notice is included in each public SVG. Both retain their source proportions. Germany sits at the upper left and the Union Jack at the upper right with identical size and mirrored fades. The latest refinement restores stronger colour and more visible moving Paper grain, while keeping the flag geometry stable and the reading area shaded.

Complete inline SVG flags include a grain/darkening filter in the same SVG group, created in code from the source geometry with its MIT notice. These stay beneath the separate complete live flag/shader composites. A pre-paint bootstrap keeps both whole flags hidden until both flag images decode and their SDK canvases have resized/drawn, then fades them in together with the hero's 360ms entrance delay and 600ms easing. There is no separate texture fade. After 2.5 seconds of visible waiting without readiness, the page reveals the static textured flags and retains that choice, preventing a late texture swap. Background tabs pause this waiting budget; JavaScript-free rendering keeps the static flags visible, and reduced motion removes the delay/transition. Context loss returns to the static texture. Final shader settings and flag geometry are unchanged. Scroll reveals prepare only offscreen elements, then follow the homepage's 600ms/20px rise and short group stagger without blur; each section intro shares one reveal.

The floating paper objects and spacious card layout at [Acctual's Altitude page](https://www.acctual.com/altitude), inspected on 14 October 2026, inspired the gentle shared movement of the boarding pass/BP26 badge and the cream reason cards with coloured icon stickers. These are native HTML/CSS interactions using the existing artwork and Lucide assets; no reference artwork, product claims or page copy was reused.
